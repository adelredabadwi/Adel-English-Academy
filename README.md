# Adel English Academy — v0.1

نسخة أولى قابلة للتشغيل لمنصة **Adel English Academy**، بإعداد **Mr. Adel Badwi**.
واجهة عربية متجاوبة واتجاه RTL، ومحتوى تعليمي إنجليزي باتجاه LTR.

## ما يعمل الآن

- صفحة رئيسية ومساران مستقلان: STEP وIELTS.
- دخول تجريبي باسم عرض واختيار مستوى، بدون بريد أو كلمة مرور.
- 6 دروس تمهيدية أصلية مع أمثلة وتسجيل الإكمال.
- تدريب من 5 أسئلة لكل مسار، وتصحيح فوري وشرح لكل إجابة.
- لوحة تقدم وسجل آخر 100 محاولة، محفوظان محليًا في المتصفح.
- مساحة كتابة IELTS تحفظ المسودة تلقائيًا وتعد الكلمات، مع قائمة مراجعة ذاتية.
- تنقل بالروابط المجزأة (hash routes)، يعمل على استضافة فرعية دون rewrite rules.

## التشغيل

يتطلب خادم التطوير Node.js 20 أو أحدث، بلا حزم خارجية أو مفاتيح API.

```bash
git clone https://github.com/adelredabadwi/Adel-English-Academy.git
cd Adel-English-Academy
npm start
```

افتح `http://localhost:3000`. لا حاجة إلى `npm install`.
بديل باستخدام Python 3: `python3 -m http.server 3000` من مجلد المشروع.
لا تفتح `index.html` عبر `file://`؛ وحدات JavaScript تحتاج خادم HTTP.

```bash
npm test
```

الاختبارات تتحقق من سلامة مفاتيح الإجابة، والتصحيح، وتفرّد الدروس، وعد الكلمات.

## البنية

```text
index.html             هيكل الصفحة
favicon.svg            أيقونة نصية أولية، وليست شعارًا رسميًا
src/styles.css         التصميم والألوان والتجاوب
src/content.js         المحتوى التعليمي وبيانات العلامة ودوال التصحيح
src/app.js             التنقل وصفحات الدروس والتدريب والكتابة والتقدم
src/store.js           عزل التخزين المحلي لتسهيل استبداله لاحقًا
server.mjs             خادم تطوير محلي بلا اعتماديات
tests/content.test.mjs اختبارات المحتوى والتصحيح
```

لتغيير الاسم الظاهر، عدّل `index.html` وبيانات `brand` في `src/content.js`؛ ولتغيير الألوان عدّل متغيرات CSS في بداية `src/styles.css`. أضف الدروس والأسئلة في `src/content.js` مع معرف فريد لكل درس.

## النشر على GitHub Pages

الكود ثابت وجاهز للنشر، لكن رفعه إلى المستودع لا يفعّل الاستضافة تلقائيًا.

1. في المستودع افتح **Settings → Pages**.
2. اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/ (root)** ثم **Save**.
4. انتظر نجاح النشر وافتح الرابط الذي تعرضه GitHub Pages.

العنوان المتوقع بعد التفعيل: `https://adelredabadwi.github.io/Adel-English-Academy/`.
هذا عنوان متوقع، وليس تأكيدًا أن النشر تم. يمكن أيضًا رفع `index.html` و`favicon.svg` ومجلد `src` إلى أي استضافة ملفات ثابتة. لا توجد خطوة build أو متغيرات بيئة مطلوبة للواجهة. `PORT` و`HOST` اختياريان لخادم التطوير فقط.

## حدود النسخة التجريبية

- الدخول تجريبي وليس مصادقة، ولا ينشئ حسابًا أو يرسل بريدًا.
- بيانات التقدم والمسودة مشتركة لكل مستخدمي المتصفح على نفس الأصل، وتبقى بعد الخروج. يمكن مسحها من صفحة «تقدمي». لا تستخدم هذه النسخة على جهاز مشترك لبيانات خاصة.
- التخزين محلي فقط؛ مسح بيانات المتصفح يفقد التقدم. عند تعذر التخزين يظهر تنبيه ويبقى التقدم في الذاكرة للجلسة.
- اختيار المستوى يحفظ تفضيلًا فقط ولا يغير المحتوى أو يقيس المستوى.
- الأسئلة تمهيدية أصلية وليست اختبار STEP/IELTS رسميًا أو محاكاة كاملة. لا يوجد تحويل للنتائج إلى درجات IELTS أو STEP.
- لا توجد قاعدة بيانات، أو صلاحيات معلم/مدير، أو رفع ملفات، أو فيديو، أو استماع، أو تصحيح AI. مساحة الكتابة تعد الكلمات فقط.
- لا تُخزّن أي كلمات مرور أو مفاتيح API في الواجهة. لا توجد خدمة خلفية في هذه النسخة.

## الخطوات التالية

1. إضافة خدمة خلفية ومصادقة بالبريد مع فصل بيانات الطلاب وصلاحيات الطالب/المعلم/المدير.
2. استبدال محول التخزين المحلي بواجهة API وقاعدة بيانات، واختبارات وصول وعزل مستخدمين.
3. توسيع بنك الأسئلة، وإضافة استماع مسجل واختبارات موقوتة بعد مراجعة المحتوى تربويًا.
4. إضافة رفع الموارد والتخزين الآمن، ثم تصحيح المقالات من الخادم مع حدود استخدام ومراجعة بشرية.
5. إضافة اختبارات متصفح إلى CI، ثم نطاق مخصص وسياسة خصوصية ونسخ احتياطي قبل استخدام بيانات حقيقية.
